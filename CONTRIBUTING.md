# Участие в разработке

Перед pull request:

1. Опишите пользовательскую проблему, которую решает изменение.
2. Не добавляйте аналитику, рекламу или скрытые сетевые запросы.
3. Добавьте тесты для расчётов и парсеров.
4. Выполните:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Изменения интерфейса должны сохранять читаемость уведомления, тёмную тему и
доступность на небольших экранах.
