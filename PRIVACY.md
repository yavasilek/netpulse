# Политика приватности NetPulse

Дата редакции: 26 июля 2026 года.

NetPulse создан как локальный сетевой инструмент без рекламы, аналитики,
регистрации и облачного профиля.

## Какие данные обрабатываются

На устройстве:

- текущая скорость передачи данных;
- тип активного подключения и признак VPN;
- публичные IPv4/IPv6;
- страна и организация публичного сетевого узла;
- локальная история последних сетевых изменений;
- настройки приложения.

## Сетевые запросы

Для определения публичного адреса и страны приложение обращается к:

- `https://ipinfo.io`;
- `https://api4.ipify.org`;
- `https://api6.ipify.org`;
- `https://api.country.is`.

При любом таком запросе удалённый сервер технически видит публичный IP
устройства. NetPulse не добавляет к запросу имя, номер телефона, рекламный
идентификатор, точную геолокацию или содержимое трафика.

Для проверки обновлений приложение обращается к публичному GitHub Releases API.

## Хранение и передача

История событий и настройки хранятся локально. NetPulse не передаёт их
разработчику и не создаёт резервную копию APK обновления вне каталога приложения.
Историю событий можно удалить из приложения.

## Разрешения

- `INTERNET` — проверка публичного IP и обновлений;
- `ACCESS_NETWORK_STATE` — состояние и тип активной сети;
- `POST_NOTIFICATIONS` — постоянный индикатор и предупреждения;
- `FOREGROUND_SERVICE` — видимый непрерывный мониторинг;
- `RECEIVE_BOOT_COMPLETED` — необязательный автозапуск;
- `REQUEST_INSTALL_PACKAGES` — установка явно подтверждённого обновления.

NetPulse не запрашивает доступ к контактам, SMS, звонкам, файлам, микрофону,
камере или точной геолокации.
