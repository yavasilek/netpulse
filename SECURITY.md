# Безопасность

Не публикуйте информацию об уязвимости в открытом issue до исправления.
Используйте приватное сообщение владельцу репозитория через GitHub.

Никогда не добавляйте в репозиторий:

- release keystore;
- пароли ключа;
- GitHub-токены;
- APK, подписанный неизвестным ключом.

Обновлятор принимает APK только с совпадающими package name, SHA-256 и
сертификатом установленного приложения.
