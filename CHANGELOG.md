# История изменений

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## [0.1.2] - 2026-07-26

### Изменено

- в статус-баре всегда показывается компактное числовое значение скорости;
- сохранённый режим обычной статической иконки автоматически заменяется входящей скоростью;
- в настройках остаётся выбор входящей, исходящей или большей из двух скоростей.

## [0.1.1] - 2026-07-26

### Исправлено

- IP и страна обновляются сразу после переключения сети или подключения VPN;
- новый запрос отменяет устаревшую проверку, поэтому старый IP больше не может вернуться в интерфейс;
- недоступный IPv6 больше не задерживает успешный IPv4;
- краткий прогрев VPN-маршрута обрабатывается автоматическим повтором;
- при замене активной сети приложение не показывает ложное отключение интернета.

## [0.1.0] - 2026-07-26

### Добавлено

- экран «Пульс» с текущими скоростями и минутным графиком;
- экран «Защита» с VPN, IPv4, IPv6, страной и ASN;
- постоянное уведомление и динамическая статусная иконка;
- мониторинг активной сети с поддержкой VPN, Wi‑Fi и мобильных подключений;
- локальная история сетевых событий;
- предупреждения об отключении VPN, смене IP и возможной IPv6-утечке;
- автозапуск, Quick Settings tile и настройки;
- безопасное обновление из GitHub Releases;
- тесты расчёта скорости и сравнения версий.
